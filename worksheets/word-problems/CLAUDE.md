# worksheets/word-problems — 兩步驟應用題紙本練習

## 目錄定位
國小三年級兩步驟應用題的**紙本練習生成器**。重點訓練「看懂題目」而非算術運算。輸出是可列印的 A4 HTML，不是互動網站。

## 檔案結構
- `word-problems.md` — **題庫 single source of truth**（含所有題目、解答、複習單編排）
- `worksheet-preview.html` — 原始 6 題預覽（版型原型，4+2 分頁）
- `worksheet-review.html` — 12 題 3 份複習單（主 6 題型各挑 2 題）
- `worksheet-compound.html` — 複名數原題 2 題（原題 + 版型原型）
- `worksheet-compound-review.html` — 複名數 6 題 2 份複習單

新增題目時：先更新 `word-problems.md` 題庫，再產出新的 worksheet HTML。

## 題型分類

### 主 6 大題型（單一單位，「看懂」訓練）

| 代號 | 題型 | 結構 | 關鍵詞 | 陷阱 |
|---|---|---|---|---|
| 1 | 合併型 | 加 → 除 | 一共、每 N 個 | 看到兩數字就亂加 |
| 2 | 序列型 | 減 → 除 | 先…後、用掉 | 無（時序明） |
| 3 | 餘量型 | 減 → 除 | 剩下、做了…後還剩 | 要倒推「用掉多少」 |
| 4 | 不足型 | 加 → 除 | 還不夠 N 元 | 看到「不夠」卻要加 |
| 5 | 幾何型 | 加 → 除 | 圍正方形/三角形 | 不足陷阱 + 幾何翻譯 |
| 6 | 反平分 | 除 → 加 | 平分給 X 和 Y 個、原來有 | 主體計數 + 運算順序翻轉 |

### 延伸題型：比較型（複名數，公斤+公克）

| 代號 | 題型 | 結構 | 陷阱 |
|---|---|---|---|
| 7 | 加→加 | A+差=B, A+B=總 | 要加兩次 |
| 8 | 減→加 | A−差=B, A+B=總 | 「A 比 B 重」求 B 要減 |

複名數題分初階/進階：
- **初階**：題目和答案都用純公克（不做單位換算）
- **進階**：題目用複名數，答案也換算成「X 公斤 Y 公克」

## 版型經驗值（CSS 參數）

**全域**
- A4 直式：`@page { size: A4 portrait; margin: 1.3cm 1.8cm }`
- 字體：`"標楷體", "DFKai-SB", "BiauKai", "Kaiti TC", serif`
- 版心寬度：21cm（`body { width: 21cm }`）
- 螢幕預覽 `padding: 1.3cm 1.8cm`；列印時 `body { padding: 0 }` 由 `@page margin` 接手

**主 6 題型單一單位版型**
- 題目：`font-size: 18pt; line-height: 1.65; text-align: justify`
- 大框（num-box）：`2.9cm × 1.5cm; border: 2.5px solid #000; border-radius: 5px`
- 小圓圈（op-circle）：`1.1cm × 1.1cm; border-radius: 50%`
- 題號（step-num）：`24pt bold`
- 等號：`25pt bold`
- 單位文字：`18pt`；必須 `white-space: nowrap` + `flex-shrink: 0` 避免被擠成直書
- step 間距：`margin: 0.55cm 0`
- 題塊間距（problem-block margin-bottom）：**1 題/頁時 1cm、4 題擠一頁時壓到 0.6cm**
- 題目下方間距（problem margin-bottom）：**1 題/頁時 0.6cm、4 題擠一頁時壓到 0.4cm**

**複名數題版型（第 3 行換算）**
- 進階題有第 ③ 行：`總重 ＝ [公斤小框] 公斤 [公克大框] 公克`
- 公斤小框（small-box）：`1.9cm × 1.5cm`（只填 1 位）
- 公克大框沿用主版型的 num-box（`2.9cm × 1.5cm`）
- 初階題（純公克）**沒有第 ③ 行**，只有 ① ② 兩步

**一頁 4 題的壓縮策略（實測）**
- @page margin 從 1.3 → 1.2cm
- problem-block margin-bottom 從 1cm → 0.6cm
- problem margin-bottom 從 0.6cm → 0.4cm
- 核心尺寸（大框、小圓圈、字體）**不縮**

## 設計原則

### 出題原則
1. **換湯不換藥**：保留結構骨架、變題材、簡化數字
2. **數字簡單**：整十/整百、進位 ≤1 次、答案在心算範圍（< 1000 為佳）
3. **題材雜化**：同題型 N 題的場域/主角/物品都不重複
4. **關鍵詞保留**：同題型的關鍵詞（一共、剩下、不夠等）一定出現

### 排版原則
1. **題型打散**：同一張 A4 的 4 題要不同題型，避免模式學習
2. **難度梯度**：一張 A4 內部「暖身 → 陷阱 → 翻轉」，第一題最簡單、最後一題最難
3. **指定壓軸**：如果有最難的題（如比較型的借位+進位），放最後一頁最後一題

### 紙本 vs 網站
這個目錄是**紙本**，不是互動網站：
- 不部署 GitHub Pages
- 不需要 JS、互動、狀態管理
- 只需要 HTML + CSS + `@page` + `@media print`
- 測試方式是「瀏覽器打開 → Ctrl+P 看列印預覽」，沒有自動測試

## 開新題型時的流程

1. 在 `word-problems.md` 新增題型區塊（結構、關鍵詞、訓練點、6 題樣本）
2. 跟使用者對齊題材、數字、難度（先列出 → 挑選 → 再排版）
3. 決定一份 A4 幾題（預設 4 題一頁）
4. 新建 `worksheet-<題型名>.html`，沿用既有版型經驗值
5. 瀏覽器驗證 Ctrl+P 列印效果
6. 題型分類若有新骨架，更新本 CLAUDE.md 的題型表
